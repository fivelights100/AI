        파일 시스템 기능 약관
        
      

      

        
이 기능은 AI가 사용자의 컴퓨터에서 파일과 폴더를 검색, 열기, 이름 변경, 생성, 내용 수정, 복사, 이동, 삭제할 수 있도록 돕습니다.

        
모든 수정/삭제/이동 작업은 후보 선택과 확인 팝업을 거치지만, 승인 후에는 실제 파일 시스템에 영향을 줄 수 있습니다.

        
삭제는 휴지통 이동으로 처리되며, 제한 경로와 위험 확장자는 계속 보호됩니다.

        
중요 파일은 반드시 팝업 내용을 직접 확인한 뒤 진행해 주세요.

      

      

        
        
      

    

  


  

    

      

        삭제 권한 경고
        
      

      
삭제 권한을 켜면 AI가 후보를 찾고, 사용자가 승인한 파일 또는 폴더를 휴지통으로 이동할 수 있습니다. 제한 경로와 위험 확장자는 계속 차단됩니다.
